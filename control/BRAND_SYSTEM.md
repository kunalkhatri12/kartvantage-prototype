## UI direction

- Modern, calm, high-trust commerce interface.
- Shopify-native interaction patterns with distinct KartVantage identity.
- Strong information hierarchy, generous spacing, short merchant-language labels, and progressive disclosure.
- Lime is an accent/action color, not a blanket text color. Navy is the primary high-contrast foreground/action color.
- Status must never depend on color alone; include text and/or icons.
- Responsive and keyboard-usable from the first shell.
- The supplied screenshots are visual references, not permission to copy legacy behavior or superseded information architecture.

## Proof requirements

For every implemented UI package, retain:

- source asset provenance and checksum
- token definitions
- automated accessibility/test results
- rendered screenshots at relevant breakpoints
- Shopify Admin preview link when an authenticated dev session exists
- owner-visible store/app verification link when the surface is connected
